# Codex Review Loop

You are running a review-only loop.

Your job:
Review anything inside the `input/` folder and write feedback inside the `reviews/` folder.

Rules:
- Do not edit files inside `input/`.
- Do not create new project files.
- Do not improve the original file directly.
- Only write review reports inside `reviews/`.
- Keep feedback practical and easy to understand.

For each review, include:
1. What the file is about
2. What is good
3. What is weak or unclear
4. Specific improvements
5. Final score out of 10

If there is nothing new to review, say that clearly.
